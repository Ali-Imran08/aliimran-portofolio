# Sitemap & Page Architecture

## Versi 1.0 (Single-Page App dengan Detail Views)
- `/` — **Landing Page Utama**
  - **Hero Section:** Fullscreen canvas, background obsidian Ono Era, foto profil di bingkai kanan-tengah, statement headline.
  - **Selected Projects:** Display kartu visual besar ala Unseen Studio dengan informasi problem-solution dan link repository/demo.
  - **About & Philosophy:** Bento Grid layout ala Bento.me untuk bio singkat, pendekatan koding, dan keahlian teknis terstruktur.
  - **Contact & Footer:** Big text CTA ala Ono Era, email direct, link GitHub/LinkedIn/CV.

- `/projects/[id]` — **Detail View / Case Study (Optional Dynamic Modal)**
  - Tampilan mendalam untuk arsitektur proyek, tangkapan layar, tantangan teknis, dan link demo.
